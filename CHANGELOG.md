# История изменений

Новые сверху. Скачать любую сборку — в [Releases](https://github.com/Chame1eon90/capslocker/releases).

## Сборка 32
- Mac: автоматическое исправление раскладки больше не тормозит набор текста.
- Mac: кнопка «Выбрать…» показывает список открытых программ (раньше программы в окне выбора были серыми — например, Telegram).
- Словари для автоисправления загружаются быстрее.

## Сборка 31
- Автоматическое исправление раскладки (по желанию, по умолчанию выключено): после пробела «ghbdtn» само становится «привет», язык переключается. Исправил зря — CapsLock вернёт слово, и больше программа его не тронет. Можно выбрать программы, где оно работает.
- Режим «Без нажатий» (по желанию): копируешь русскую фразу — в буфере уже английский перевод, остаётся нажать Ctrl+V (на Mac ⌘V). В игре программа ничего не нажимает. Тоже можно выбрать программы.

## Сборка 29
- Сборки на GitHub идут по порядку, у каждой есть описание «Что нового». Старые сборки 1–9 и первые Mac-сборки удалены (их изменения описаны ниже).
- Mac: выпускается только версия для чипов M1–M4, версии для Intel больше нет.

## Сборка 26
- В каждой сборке на GitHub — раздел «Что нового», история изменений в файле CHANGELOG. (Файла для Windows в этой сборке нет.)

## Сборка 25
- Словарь WoW: около 120 новых слов — классы, подземелья и рейды (БРД, Страт, МК, Оня, БВЛ, Накс, ЦЛК…), групповые сокращения (лфм, нид/грид, пулл, ресни, суммон, овца, сап…), чат (гг, вп, хз, пж…).
- Строки вида «рус -> english» переводятся только с русского: своё «нид» станет need, а чужое «I need help» не превратится в «I нид help».
- Кнопка «Добавить новые» в редакторе словаря — дописывает новые стандартные слова, не трогая твои правки.

## Сборка 24
- Окно разложено по вкладкам: «Перевод», «Ошибки», «Раскладка», «Настройки».
- На вкладке «Ошибки» — своё поле «Проверить текст»; строка состояния видна на любой вкладке.
- Офлайн-модели, словарь и автозапуск — на вкладке «Настройки».

## Сборка 23
- Выключенные функции гаснут в окне.
- Пунктуацию можно выключить полностью — тогда гаснет и её список программ.

## Сборка 22
- Отдельные переключатели «Перевод» и «Проверка ошибок» — в окне и в меню трея. Выключенная функция освобождает свою клавишу.

## Сборка 21
- Повторная сборка того же кода, что в сборке 20.

## Сборка 20
- Плашку можно поставить и в левые углы (сверху и снизу).
- Плашка точно прижимается к краю экрана при масштабе 150%.

## Сборка 19
- Плашка встаёт на правильное место при масштабе экрана 125–150%.

## Сборка 18
- Mac: программа подписана постоянным сертификатом — разрешения «Универсальный доступ» и «Мониторинг ввода» сохраняются после обновлений.

- Всплывающая плашка с переводом входящих английских сообщений поверх игры.
- Подготовка постоянной подписи для Mac.

## Сборка 4

- Описание программы на странице GitHub.

## Сборка для macOS 3

## Сборка для macOS 2
- Русский текст больше не превращается в «кракозябры» при копировании (буфер обмена через системный механизм macOS).
- CapsLock исправляет и текст, который был в поле ещё до запуска программы.

## Сборка для macOS 1
- Первая версия для macOS: перевод фразы в чате RU → EN по ⌃⌥T, перевод скопированного английского.
- Исправление раскладки по CapsLock: «ghbdtn» → «привет», повторное нажатие — отмена, удержание — обычный Caps Lock.
