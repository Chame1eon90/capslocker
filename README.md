# Капслокер

Перевод чата (русский ⇄ английский) и исправление раскладки одним нажатием CapsLock.

- `windows/` — исходники версии для Windows.
- `mac/` — версия для macOS. Собирается автоматически: вкладка **Actions**, готовые файлы лежат в **Releases**.

## Установка на Mac

1. Открой **Releases** (справа на странице репозитория) и скачай:
   - `Capslocker-macOS-Apple-M.zip` — для Mac на чипах M1, M2, M3, M4;
   - `Capslocker-macOS-Intel.zip` — для Mac на Intel.
   Какой чип у тебя: меню  → «Об этом Mac» → строка «Чип» или «Процессор».
2. Распакуй архив и перетащи **Capslocker** в «Программы».
3. Первый запуск. Программа не подписана платным сертификатом Apple, поэтому macOS её
   заблокирует. Нажми «Готово», затем открой **Системные настройки → Конфиденциальность и
   безопасность**, пролистай вниз и нажми **«Всё равно открыть»** напротив Capslocker.
   Можно и через Терминал одной командой:
   `xattr -cr /Applications/Capslocker.app`
4. Разрешения. Капслокер попросит доступ: в **Системные настройки → Конфиденциальность и
   безопасность** включи Capslocker в **«Универсальный доступ»** и в **«Мониторинг ввода»**.
   Через пару секунд программа сама заметит разрешение.
5. В **Системные настройки → Клавиатура → Источники ввода** должны быть добавлены
   русская и английская раскладки.

После каждого обновления программы macOS может попросить выдать разрешения заново
(выключи и снова включи Capslocker в обоих списках).

## Как пользоваться на Mac

**Раскладка**
- CapsLock — исправить набранное («ghbdtn rfr ltkf» → «привет как дела») и сменить язык.
- CapsLock ещё раз — отменить.
- Держать CapsLock — обычный Caps Lock.
- Shift + CapsLock — переделать выделенный текст.

Пока программа запущена, CapsLock переназначен на ней (так macOS не включает Caps Lock сама).
При выходе (⌘Q) всё возвращается как было. Если CapsLock вдруг перестал работать после
сбоя — запусти Капслокер и выйди через ⌘Q или просто перезагрузи Mac.

**Перевод**
- Напиши фразу в чате и нажми **⌃⌥T** (Control + Option + T) — фраза заменится английской.
  Сочетание можно поменять в окне программы.
- Скопированный английский текст (⌘C) переводится на русский в «Истории».

**Проверка ошибок**
- **⌃⌥R** — исправить опечатки в строке чата. Если перед этим выделить часть текста,
  проверится только выделенное; исправленный текст остаётся в буфере обмена.
- Кнопка «Ошибки» в «Быстром переводе».
Проверка работает через интернет (Яндекс.Спеллер, запасной — LanguageTool).

Окно закрывается — программа продолжает работать. Вернуть окно — клик по значку в Dock,
выйти — ⌘Q.
