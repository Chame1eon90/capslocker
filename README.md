# Капслокер

Маленькая программа для Windows и macOS, которая помогает общаться в игровом чате
(например, в World of Warcraft) и вообще печатать на двух языках.

**Скачать:** [последняя версия](https://github.com/Chame1eon90/capslocker/releases/latest)
- `Capslocker-Windows.zip` — для Windows 10/11;
- `Capslocker-macOS-Apple-M.zip` — для Mac на чипах M1–M4;
- `Capslocker-macOS-Intel.zip` — для Mac на Intel.

## Что умеет

### Перевод RU ⇄ EN
- Пишешь фразу по-русски в чате игры, жмёшь клавишу — фраза заменяется английской.
  Команды чата сохраняются: `/g привет всем` → `/g hello everyone`.
- Скопированный английский текст сразу переводится на русский в окне программы.
- Онлайн-сервисы на выбор: Google, Microsoft (Bing), Яндекс, MyMemory — с автоматической
  подстраховкой, если какой-то не отвечает. Кнопка «Проверить» показывает, какие работают.
- Офлайн-перевод без интернета: быстрая модель Argos, а на Windows ещё и качественная
  модель Tencent HY-MT. Модели грузятся в память только когда нужны и выгружаются после простоя.

### Исправление раскладки по CapsLock
- Набрал «ghbdtn rfr ltkf» — нажал CapsLock — стало «привет как дела», язык переключился.
- CapsLock ещё раз — отмена. Держать CapsLock — обычный Caps Lock.
- Shift + CapsLock — переделать выделенный текст.
- Работает и с текстом, который был в поле ещё до запуска программы.

### Проверка ошибок
- Отдельная клавиша исправляет опечатки в строке чата; если выделить часть текста —
  только в выделенном. Результат остаётся в буфере обмена.
- По желанию — исправление перед каждым переводом (по умолчанию выключено).
- Через Яндекс.Спеллер, запасной вариант — LanguageTool.

### Горячие клавиши по умолчанию

| Действие | Windows | macOS |
|---|---|---|
| Перевести фразу в чате | F9 | ⌃⌥T |
| Исправить ошибки | F8 | ⌃⌥R |
| Исправить раскладку | CapsLock | CapsLock |

Клавиши перевода и проверки можно поменять в окне программы.

## Установка

### Windows
1. Скачай и распакуй `Capslocker-Windows.zip`, запусти `Capslocker.exe`.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» →
   «Выполнить в любом случае».
3. Программа живёт в трее рядом с часами; закрытие окна её не выключает.

### macOS
1. Скачай архив под свой чип (меню  → «Об этом Mac»), распакуй и перетащи
   **Capslocker** в «Программы».
2. Первый запуск: macOS заблокирует программу без платной подписи Apple. Открой
   **Системные настройки → Конфиденциальность и безопасность** и нажми
   **«Всё равно открыть»**. Или в Терминале: `xattr -cr /Applications/Capslocker.app`
3. Включи Capslocker в **«Универсальный доступ»** и **«Мониторинг ввода»**
   (там же, в «Конфиденциальность и безопасность»).
4. В настройках клавиатуры должны быть русская и английская раскладки.

После обновления macOS может попросить разрешения заново: удали Capslocker из обоих
списков кнопкой «–» и добавь снова через «+».

Пока программа запущена, CapsLock на Mac переназначен на неё; после выхода (⌘Q) всё
возвращается как было.

## Обновление
Кнопка **«Обновить»** вверху окна: программа проверит GitHub, скачает новую сборку,
заменит себя и перезапустится. Сама в интернет за обновлениями не ходит — только по кнопке.
На Mac после обновления может понадобиться снова выдать разрешения (см. выше).

## Конфиденциальность
Программа не записывает, что ты печатаешь. В интернет уходят только фразы, которые ты
сам отправляешь на перевод или проверку, — в выбранный онлайн-сервис.

## Для разработки
- `windows/` — исходники версии для Windows, `mac/` — для macOS.
- Сборка идёт автоматически на GitHub после каждого изменения (вкладка **Actions**),
  готовые файлы появляются в **Releases**.
